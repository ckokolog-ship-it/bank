# Bank

Τραπεζική εφαρμογή σε Oracle (PL/SQL), για μάθηση, επίδειξη και παρακολούθηση λογαριασμών: πελάτες, λογαριασμοί καταθέσεων, πιστωτικές κάρτες και δάνεια, με κινήσεις σε διπλογραφία και υπολογισμό τόκων. Όλα τα δεδομένα επίδειξης είναι τυχαία.

Χτίζεται σε βήματα, ένα pull request το καθένα.

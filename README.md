# 🏦 Bank

Για μάθηση, επίδειξη και παρακολούθηση λογαριασμών. **Όλα τα δεδομένα επίδειξης είναι τυχαία:** πελάτες, ΑΦΜ (με σωστό ψηφίο ελέγχου, που δεν ανήκουν σε κανέναν), IBAN τράπεζας «999» που δεν υπάρχει.

> **Η βασική ιδέα:** όλοι οι κανόνες είναι **μία φορά**, στη βάση, στο πακέτο `BK_CORE`, και κάθε κίνηση γίνεται σε **διπλογραφία**:
> - **ισοσκέλιση:** κάθε εγγραφή έχει χρεώσεις και πιστώσεις που ισοσκελίζονται·
> - **καμία διαγραφή:** τίποτα δεν αλλάζει και τίποτα δεν σβήνεται· ένα λάθος διορθώνεται με αντιλογισμό·
> - **υπόλοιπα:** βγαίνουν από τις κινήσεις, και η όψη `BK_CHECK` είναι άδεια όταν όλα συμφωνούν.

## 🚀 Γρήγορη εκκίνηση

```bash
cd db
sqlplus system@FREEPDB1 @CREATE_USER.sql                 # ο χρήστης BANK
export NLS_LANG=GREEK_GREECE.AL32UTF8                     # Windows: set NLS_LANG=...
sqlplus bank@FREEPDB1 @INSTALL.sql demo                   # πίνακες, πακέτο, και ένας χρόνος τυχαίων κινήσεων
sqlplus bank@FREEPDB1 @BK_CHECK.sql                       # συμφωνούν όλα; (καμία γραμμή: ναι)
```

Με το `demo` μπαίνουν 40 πελάτες, 77 λογαριασμοί (8 σε USD ή GBP) 12 πιστωτικές κάρτες και 8 δάνεια, με έναν χρόνο κινήσεων και ισοτιμιών, μέρα με τη μέρα:
- μισθοί, ενοίκια, αναλήψεις, πληρωμές με κάρτα, μεταφορές, μερικοί αντιλογισμοί, από το γκισέ, το e-banking και τα ATM·
- κανόνες κινήσεων: όρια στα ATM, προμήθειες, ταμιευτήρια χωρίς μεταφορές σε άλλη τράπεζα·
- κλείσιμο κάθε μέρας, με τους τόκους της·
- μια αλλαγή επιτοκίου στη μέση του χρόνου.

Μπαίνουν σε περίπου 10 δευτερόλεπτα.

Οι σελίδες, στο http://<server>:8091/ (στο Linux ως υπηρεσία: [docs/ODIGIES_WEB.md](docs/ODIGIES_WEB.md)):

```bash
sudo ~oracle/bank/api/install_service.sh                                          # ζητά τον κωδικό του BANK· χτίζει και ξεκινά
sudo ~oracle/bank/api/install_service.sh --add-user admin ADMIN "Όνομα Επώνυμο"   # ο πρώτος χρήστης των σελίδων
```

## 🧪 Tests

Τα tests τρέχουν πάνω σε ζωντανή βάση, χωρίς mocks· τα tests του REST ξεκινούν και το jar:

```bash
pip install pytest oracledb
(cd api && ./mvnw -q -B package -DskipTests)
BANK_DSN=bank/<κωδικός>@localhost:1521/FREEPDB1 python -m pytest -q tests
```
